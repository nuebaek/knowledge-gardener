### Day 1 (06/01) — 데이터 준비 + 고전 ML

#### 1-1. 데이터 전처리 (Data Preprocessing)

> 모델 학습 전 원본 데이터를 정제하고 변환하는 과정

**사용 이유:**
AI 모델의 성능은 데이터 품질에 달려 있다. 결측값, 스케일 차이, 범주형 데이터를 그대로 넣으면 모델이 제대로 학습하지 못한다.

**핵심:**
- **결측값 처리**: 비어있는 값(`NaN`)을 평균·중간값으로 대체(`fillna`)하거나 행 제거(`dropna`)
- **정규화**:
  - `MinMaxScaler`: 최솟값·최댓값 기반으로 **0~1** 변환
  - `StandardScaler`: 평균=0, 표준편차=1 (z-score)
  - `fit_transform()`: sklearn 메서드. fit(통계 계산) + transform(변환) 한 번에 수행
- **원-핫 인코딩**: 범주형 → 수치형. 모델은 숫자만 계산할 수 있기 때문.
  - `pd.get_dummies()`: 카테고리 수만큼 컬럼 생성, 해당 1 / 비해당 0

**비유**
> 전처리 = 석유 채굴. 원유를 그냥 쓸 수 없듯이 원시 데이터를 그냥 모델에 넣을 수 없다. 정제 과정이 필수적

**코드**
```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler
import pandas as pd

# 정규화
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)

# 원-핫 인코딩
df_encoded = pd.get_dummies(df, columns=['category'])
```

#### 1-2. 데이터 증강 (Data Augmentation)

> 원본 데이터를 변형해 인공적으로 데이터 수를 늘리는 과정

**사용 이유**

데이터가 부족하거나 편향되어 있으면 모델이 과적합될 수 있다. 조금씩 다른 변형 데이터를 추가로 학습시켜 **일반화 성능을 높인다**.

**핵심**

- 적용 기법: 회전, 반전, 평행이동, 크기조절
- `PIL` 라이브러리로 이미지 조작
- **잘못된 증강이 편향을 만드는 경우**: 실제 데이터 분포와 다른 패턴을 만들면 오히려 학습을 망칠 수 있음
  - e.g. 의료 이미지를 상하반전 → 실제 존재하지 않는 패턴을 모델이 학습

**비유**
> 영어 공부할 때 같은 문장을 다양한 방식으로 바꿔 연습하는 것. 새 문장이 아니라 변형이지만 실력은 는다.

#### 1-3. 데이터 분할 (Data Split)

> 전체 데이터를 Train / Validation / Test로 분리하는 과정

**사용 이유:**
같은 데이터로 학습하고 평가하면 모델이 암기한 건지 진짜 이해한 건지 구분이 안 된다. 역할을 나눠야 공정한 평가가 가능하다.

**핵심**

| 종류 | 역할 | 비유 |
|------|------|------|
| Train | 학습 | 공부 |
| Validation | 하이퍼파라미터 튜닝 | 모의고사 |
| Test | 최종 성능 평가 | 실제 시험 |

- `train_test_split`: sklearn 함수. test 비율 지정하면 랜덤 분할
- `random_state` 설정 이유: 재현 가능성 확보. 같은 숫자면 항상 동일한 분할 결과

**비유**
> Train = 교과서로 공부 / Validation = 모의고사로 약점 파악, 전략 수정 / Test = 수능

#### 1-4. KNN (K-Nearest Neighbors)

> 새로운 데이터가 오면 거리 공간에서 가장 **가까운 K개 이웃을 찾아 다수결로 분류/예측**하는 알고리즘

**사용 이유**

별도 학습 과정이 없고 직관적이라, 데이터 분포를 그대로 활용하는 단순한 분류 문제에 쓰기 좋다.

**핵심**

- 거리 척도: 유클리디안(직선 거리) / 맨해튼(택시 거리)
- K값이 **너무 작으면**: 노이즈에 민감 → 과적합 위험
- K값이 **너무 크면**: 세밀한 차이를 놓침 → 과소적합 위험
- **훈련 과정의 특이점**: 가중치를 추정하지 않음. 전체 훈련 데이터를 저장하고 예측 시마다 거리 계산

---

#### 1-5. SVM (Support Vector Machine)

> **클래스 사이의 마진(여백)을 최대화하는 초평면(결정 경계)** 을 찾는 지도학습 알고리즘

**사용 이유**

마진을 최대화한 결정 경계는 새로운 데이터에도 일반화가 잘 된다. 특히 고차원 데이터에서 강력하다.

**핵심**

- **초평면(Hyperplane)**: 2D에서는 선($ax+by+c=0$), 3D에서는 면($ax+by+cz+d=0$), 4차원 이상은 수학적 일반화 명칭 → '초평면'
- **마진(Margin)**: 초평면과 가장 가까운 데이터 포인트(서포트 벡터)들 사이의 거리. 이를 최대화하는 초평면을 찾는 것이 목표
- **서포트 벡터(Support Vector)**: 초평면에 가장 가까이 위치한 데이터 포인트들. **이 점들만 결정 경계에 영향을 줌**

---

#### 1-6. Random Forest

> 수많은 Decision Tree를 랜덤하게 만들어 앙상블(다수결)로 예측하는 모델

**사용 이유**

단일 Decision Tree는 과적합에 약하다. 여러 트리의 다수결을 취하면 하나가 과적합해도 상쇄된다.

**핵심**

- **Decision Tree**: 데이터 특성을 기준으로 조건을 분기해 예측하는 트리 구조. 분류/회귀 모두 사용 가능.
- **앙상블(Ensemble) 기법 세부 종류**:
  - **배깅(Bagging/Bootstrap Aggregating)**: 랜덤 샘플로 여러 모델을 독립적으로 병렬 학습 → 결과를 평균/투표로 합침. **Random Forest = 배깅 방식.**
  - **부스팅(Boosting)**: 이전 모델이 틀린 샘플에 더 집중해서 순차적으로 보완 학습 (e.g. XGBoost, AdaBoost)
  - **스태킹(Stacking)**: 여러 모델의 예측값을 또 다른 메타 모델의 입력으로 사용
- **과적합에 강한 이유**: **각 트리가 다른 랜덤 샘플/특징으로 학습 → 하나의 트리가 과적합해도 다수결로 상쇄됨**

**비유**
> 혼자 판단하지 않고 전문가 100명에게 의견을 모아 다수결로 결정한다.

#### 1-7. Naive Bayes

> 모든 특성이 서로 독립적이라는 Naive한 가정 하에 베이즈 정리로 확률을 계산하는 분류 모델

**사용 이유**

독립 가정 덕분에 계산이 단순하고 빠르다. 텍스트 분류(스팸 필터 등)에서 특히 효과적이다.

**핵심**

- **"Naive"한 가정**: 모든 피처가 서로 완전히 독립이라는 가정. 현실에선 독립이 아닌 경우가 많지만, 이 가정 덕에 계산이 단순해짐
- **베이즈 정리**: $$P(A|B) = P(B|A) × P(A) / P(B)$$
  - "B가 일어났을 때 A 확률"을 "A가 일어났을 때 B 확률"로 계산하는 공식
- **가우시안 나이브 베이즈**: 피처가 연속형(수치형)일 때 사용. 각 클래스 내 데이터가 정규분포를 따른다고 가정.

**비유**
> 스팸 필터: \
> "무료", "당첨" 단어가 있을 때 스팸일 확률 = 각 단어가 스팸에 등장할 확률(독립 가정) × 사전 스팸 확률

---

#### 1-8. 고전 ML의 한계

> **왜 딥러닝이 필요해졌나**

고전 ML은 알고리즘(SVM, KNN 등)을 사람이 선택해줘야 한다. 이미지, 텍스트처럼 비선형적이고 복잡한 데이터에서는 특징(Feature) 자체를 사람이 설계해야 한다. **딥러닝은 특징 추출까지 데이터에서 스스로 학습**한다.

```
Rule-based  → 사람이 규칙을 하드코딩
고전 ML       → 사람이 알고리즘을 선택, 특징은 직접 설계
딥러닝        → 알고리즘도, 특징 추출도 스스로
```

### Day 2 (06/02) — 딥러닝 기초

#### 2-1. 퍼셉트론 (Perceptron)

> 인공신경망의 기본 단위. 입력값에 가중치를 곱하고 합산한 뒤 활성화함수를 적용해 단일 출력을 생성하는 선형 이진 분류기

**사용 이유**

뇌의 뉴런이 여러 신호를 받아 하나의 출력을 내듯이, 여러 입력을 통합해 하나의 판단을 내리는 기본 단위가 필요하다.

**핵심**

- 구성: **가중합 + 활성화함수**
- 가중합 수식: $z = w₁x₁ + w₂x₂ + ... + b$ (pre-activation. 활성화함수 적용 후: $a = σ(z)$)
- 이 출력이 다음 층에서 하는 역할: 다음 층 노드의 입력값 → 다시 가중합 → 활성화함수 → 출력 반복

**비유**
> 뇌의 뉴런. 여러 곳에서 신호를 받아 일정 임계값을 넘으면 다음 뉴런으로 신호를 보낸다.

---

#### 2-2. 활성화함수 (Activation Function)

> 가중합에 비선형성을 부여해 신경망이 복잡한 패턴을 학습할 수 있게 하는 함수

**사용 이유**

활성화함수가 없으면 층을 아무리 쌓아도 수학적으로 선형 변환 1개와 동일해진다. 비선형 함수를 끼워야 층을 쌓는 의미가 생기고 복잡한 패턴을 학습할 수 있다.

**핵심**

> 활성화함수 없이 층을 쌓으면: \
> 층1: $W₁x$, 층2: $W₂(W₁x) = (W₂W₁)x$ → 행렬 하나로 압축됨. \ 
> 100층을 쌓아도 선형 모델 1개랑 동일.

| 종류 | 범위 | 장점 | 단점 | 언제 쓰나 |
|------|------|------|------|-----------|
| Step | 0 or 1 | 구조 단순 | 기울기 없음(학습 불가) | 초기 단층 퍼셉트론(역사적) |
| Sigmoid | 0~1 | 확률값 표현 | 기울기 소실 | 이진분류 출력층 |
| Tanh | -1~1 | 출력 중심이 0 | 기울기 소실 | RNN 은닉층 |
| ReLU | 0~∞ | 기울기 소실 완화, 빠름 | Dying ReLU(음수 뉴런 죽음) | 은닉층 기본값(de-facto 표준) |

> [!NOTE]
> **기울기 소실 (Vanishing Gradient)**
>
> **왜 발생하나**: Sigmoid/Tanh는 입력이 크거나 작으면 기울기가 거의 0에 수렴. 층을 거칠수록 곱해지면서 더 작아짐.
>
> **ReLU가 어떻게 완화하나**: 양수 구간에서 기울기가 항상 1로 유지됨 (max(0, x) → 양수면 그대로 전달)

**출력층 활성화함수 선택 기준:**

| 태스크 | 함수 | 이유 |
|--------|------|------|
| 이진 분류 | Sigmoid | 0~1 확률 하나 출력 |
| 다중 분류 | Softmax | 클래스별 확률, 합이 1 |
| 회귀 | 없음(Linear) | 값 범위 제한 불필요 |

**비유**
> 뉴런이 신호를 "꺾어주는" 스위치. 꺾어야 여러 층이 의미 있게 쌓인다.

#### 2-3. ANN / FCNN

> **ANN(Artificial Neural Network)**: 인간의 뇌 뉴런 구조를 모방한 알고리즘. 여러 층의 퍼셉트론을 연결한 구조. \
> **FCNN(Fully Connected Neural Network)**: 모든 뉴런이 이전 층의 모든 뉴런과 연결된 특수한 형태의 ANN.

**사용 이유**

단층 퍼셉트론으로는 XOR 같은 비선형 문제를 풀 수 없다. 은닉층을 추가한 다층 구조(MLP)가 이를 해결하면서 딥러닝이 발전했다.

**핵심**

- **XOR 문제와 MLP 등장**: 단층 퍼셉트론(선형 분류기)은 XOR(서로 다를 때만 1) 문제를 선형으로 분리할 수 없어 해결 불가 → 은닉층을 추가한 다층 MLP가 이를 해결 → 딥러닝 발전의 직접적 계기
- 입력 데이터 형태: **주로 1차원 배열** (이미지 등 다차원은 Flatten 필요)
- **FCNN의 단점 (이미지에서)**:
  - **공간 정보 손실**: 이미지를 1D로 펼치면 픽셀의 상하좌우 위치 관계가 파괴됨
  - **파라미터 폭증**: 모든 노드가 연결 → 이미지 입력 시 가중치 수 폭발 → 메모리, 과적합 문제

**비유**
> 은닉층 = 블랙박스. 사용자 입장에선 그냥 입력→출력이지만, 엔지니어는 반드시 내부를 알아야 한다.

### Day 3 (06/03) — 학습 파이프라인

#### 3-1. 순전파 (Feed Forward)

> 입력층에서 은닉층 → 출력층 순으로 앞으로 전진하면서, 각 층에서 가중합과 활성화함수를 적용해 예측값을 도출하는 과정

**사용 이유**

모델이 현재 가중치로 "얼마나 예측을 잘 하는지" 먼저 계산해야, 얼마나 틀렸는지 알 수 있다.

**핵심**

- 방향: 입력층 → 은닉층 → 출력층 (앞으로만 진행)
- 각 층에서: 가중합 계산 → 활성화함수 적용 → 다음 층으로 전달

---

#### 3-2. 손실 함수 (Loss Function)

> 예측값($ŷ$)과 실제 정답($y$)의 차이를 정량적으로 측정하는 함수. 이 값을 줄이는 방향으로 학습.

**사용 이유**

"얼마나 틀렸는지"를 하나의 숫자로 표현해야 그 숫자를 줄이는 방향으로 학습할 수 있다.

**핵심**

| 종류 | 태스크 | 계산 방식 |
|------|--------|-----------|
| MSE | 회귀 | (예측-실제)²의 평균 |
| MAE | 회귀 | \|예측-실제\|의 평균 |
| Cross Entropy | 분류 | $-Σ ylog(ŷ)$, 정답 확률이 높을수록 손실↓ |
| Hinge Loss | 분류(SVM) | 마진 기반 손실 |

**비유**
> 채점 기준. 정답이랑 얼마나 다른지 점수로 환산한다.

---

#### 3-3. 역전파 (Backpropagation)

> 출력층에서 계산된 손실(오차)을 바탕으로, 각 가중치가 오차에 얼마나 기여했는지 gradient를 계산하는 과정. 출력층 → 은닉층 방향으로 역행.

**사용 이유**

순전파로 얼마나 틀렸는지 알았다면, 이제 "어떤 가중치가 얼마나 책임이 있는지" 계산해야 가중치를 올바르게 수정할 수 있다.

**핵심**

- **Loss vs Backprop 차이**:
  - Loss Function: **얼마나** 틀렸는지
  - Backpropagation: **누가** 얼마나 틀렸는지 (각 가중치의 기울기 계산)
- **Chain Rule (연쇄법칙)**: 합성함수의 미분 규칙. $$f(g(x))' = f'(g(x)) × g'(x)$$ 여러 층을 거쳐 gradient를 역방향으로 전파할 때 사용.
- **결과물은 가중치가 아니라 Gradient**: 역전파의 결과는 "가중치를 얼마나 어느 방향으로 바꿔야 하는지"의 방향·크기 정보. 실제 가중치 수정은 옵티마이저가 함.
- **층마다 gradient 흐름**: $$∂L/∂w = (∂L/∂output) × (∂output/∂hidden) × (∂hidden/∂w)$$ 
     각 층의 미분을 연쇄적으로 곱해서 역방향으로 전달

**비유**
> 시험을 망쳤을 때 "어느 파트에서 얼마나 실수했는지" 오답 분석하는 것. 실제로 틀린 답을 고치는 건(가중치 업데이트) 그 다음 단계.

---

#### 3-4. 경사 하강법 (Gradient Descent)

> 손실 함수가 감소하는 방향(gradient의 반대)으로 가중치를 조금씩 이동시키는 최적화 알고리즘

**사용 이유**

역전파로 gradient를 구했으면, 그 방향의 반대로 가중치를 이동시켜야 손실이 줄어든다.

**핵심**

- 수식: $θ = θ - η∇L$
  - **$θ$**: 가중치(weight) — 업데이트 대상
  - **$η$ (Learning Rate)**: 학습률 — 한 번에 이동하는 보폭 크기
  - **$∇L$**: gradient — 손실 함수의 기울기 (가장 가파르게 증가하는 방향)
- **Learning Rate가 너무 크면**: 최적점을 건너뛰어 손실이 발산하거나 진동
- **Learning Rate가 너무 작으면**: 학습 속도 너무 느리고 Local Minima에 빠질 위험
- **Local Minima vs Global Minima**: Local = 부분적 최솟값 / Global = 진짜 전체 최솟값

---

### Day 4 (06/04) — CNN + 최적화 알고리즘

#### 4-1. CNN (Convolutional Neural Network)

> FCNN의 공간 정보 손실 + 파라미터 폭증 문제를 해결하기 위해 등장한 이미지 특화 신경망

**사용 이유**

이미지에는 픽셀의 공간적 위치 관계(인접 픽셀 간 패턴)가 중요하다. FCNN은 이를 파괴하지만, CNN은 필터를 슬라이딩해 공간 구조를 보존하면서 특징을 추출한다.

**핵심 — Convolution Layer**

> 작은 필터(커널)가 이미지를 슬라이딩하며 가중합을 계산해 특징 맵(Feature Map)을 생성하는 특징 추출 레이어

- **필터(커널)**: 이미지의 특정 패턴(엣지, 질감 등)을 감지. 슬라이딩하며 각 위치에서 가중합 → Feature Map 생성
- **채널(Channel)의 의미**: 추출된 특징의 종류 수
  - 초기 층(32채널): 단순한 선, 모서리, 엣지 32종류
  - 깊은 층(128채널+): 눈, 코, 바퀴 등 고수준 특징 128종류 이상
- **Stride**: 필터가 한 번에 이동하는 픽셀 수. 클수록 출력 크기↓
- **Padding**: 입력 이미지 테두리에 0을 추가해 출력 크기를 원본과 같게 유지

**핵심 — Pooling Layer**

> 특징 맵의 공간 크기를 줄여 다운샘플링하는 레이어. 연산량 감소 + 과적합 방지.

| 종류 | 방식 | 언제 쓰나 |
|------|------|-----------|
| Max Pooling | 영역 내 최댓값 선택 | 이미지 분류 (뚜렷한 특징 강조) |
| Average Pooling | 영역 내 평균값 계산 | 전체적 분포 반영 필요 시 |

- 풀링 후 채널 수는 변하지 않음. 공간 크기(H, W)만 줄어든다.

**핵심 — CNN 전체 흐름 + 차원 추적**

```
입력 이미지: [배치, 채널, H, W]
↓ Conv2d(3, 32, 3, padding=1)
[배치, 32, H, W]
↓ MaxPool2d(2, 2)
[배치, 32, H/2, W/2]
↓ Conv2d(32, 64, 3, padding=1)
[배치, 64, H/2, W/2]
↓ MaxPool2d(2, 2)
[배치, 64, H/4, W/4]
↓ Flatten
[배치, 64 × H/4 × W/4]
↓ Linear → 분류
[배치, 클래스 수]
```

> CIFAR-10 (H=32, W=32): Flatten 후 차원 = 64 × 8 × 8 = **4096**

**코드**

```python
nn.Conv2d(in_channels, out_channels, kernel_size, padding)
# in_channels: 이전 층의 out_channels
# out_channels: 추출할 특징 종류 수
# kernel_size: 필터 크기 (보통 3)
# padding: 출력 크기 유지 여부
```

**비유**
> 눈이 이미지를 보는 방식. 전체를 한 번에 보지 않고, 작은 영역을 훑으며 엣지 → 형태 → 얼굴 순으로 단계적으로 추상화한다.

---

#### 4-2. 최적화 알고리즘 (Optimizer)

> 역전파로 계산한 gradient를 사용해 가중치를 실제로 업데이트하는 알고리즘

**사용 이유**

고정 학습률의 문제: 학습 초기엔 큰 보폭, 최적점 근처엔 작은 보폭이 필요하다. 파라미터마다 최적 보폭도 다른데 동일하게 적용된다. 이를 해결하기 위해 적응형 옵티마이저가 등장했다.

**핵심 — GD 종류 비교**

| 종류 | 배치 크기 | 특징 |
|------|-----------|------|
| BGD | 전체 | 전체 평균 gradient로 1번 업데이트. 안정적이나 느림 |
| MBGD | 미니배치(e.g. 64) | 배치 단위로 여러 번 업데이트. 균형 잡힌 표준 방식 |
| SGD | 1개 | 샘플 1개마다 업데이트. 빠르고 Local Minima 탈출 가능하나 불안정 |

**핵심 — 적응형 옵티마이저**

**Adagrad**
- 파라미터마다 지금까지의 gradient 제곱합($G_t$)을 누적해서 학습률을 나눠줌
- 단점: 분모 $G_t$가 계속 커져서 학습률이 0에 수렴 → 학습 조기 중단

**RMSprop**
- Adagrad 단점 보완: $G_t$를 그냥 더하지 않고 **지수 이동 평균(EMA)** 적용
- $G_t = γ·G_{t-1} + (1-γ)·g_t²$ → 오래된 gradient는 감쇠, 분모가 무한히 커지는 것을 막음

**Adam**
- **Momentum + RMSprop 결합**
- 1차 모멘텀(mt): 기울기의 EMA → 관성. SGD의 지그재그 진동 억제
- 2차 모멘텀(vt): 기울기 제곱의 EMA → 분산 제어. 파라미터별 학습률 조절
- **왜 딥러닝 기본값인가**: 관성으로 안정적 + 적응형 학습률로 파라미터마다 최적 보폭 자동 조절 + Local Minima 탈출 쉬움

> **Momentum이란**: 공이 경사면을 내려올 때 관성을 갖는 것처럼, 이전 gradient 방향을 기억해 같은 방향으로 계속 나아가게 하는 메커니즘. 방향 진동 억제.

> **EMA(지수 이동 평균)이란**: 최근 값에 더 큰 비중, 오래된 값은 지수적으로 감쇠. $v = β·v_{prev} + (1-β)·현재값$

### Day 5 (06/05) — 수학적 기반 + PyTorch 실습

#### 5-1. 파라미터 수 계산

> 파라미터(Parameter) = 가중치(Weight) + 편향(Bias)

**사용 이유**

모델의 파라미터 수를 알아야 메모리 요구량(OOM 가능성)과 학습 복잡도를 예측할 수 있다.

**핵심**

- **Conv Layer**: `(in_ch × kernel × kernel × out_ch) + out_ch`
- **FC Layer**: `in × out + out`
- **OOM(Out of Memory)**: 모델 파라미터 수 × 데이터 크기가 GPU VRAM 초과 시 발생. 큰 배치사이즈, 깊은 모델, 고해상도 이미지 등이 원인.

---

#### 5-2. 엔트로피 (Entropy)

> 클로드 섀넌(1948): 확률 분포의 불확실성,복잡도를 수치로 표현한 것. 정보를 인코딩하는 데 필요한 평균 비트 수.

**사용 이유**

크로스 엔트로피(분류 손실함수)의 수학적 기반. 엔트로피를 먼저 이해해야 크로스 엔트로피의 의미를 알 수 있다.

**핵심**

- 수식: $$H(P) = -Σ P(x) · log₂P(x)$$
- **엔트로피가 크다** = 더 불확실하다, 예측하기 어렵다, 더 많은 비트가 필요하다
- e.g. 맑음(0.5), 흐림(0.25), 비(0.25) → H = 1.5비트

**비유**
> 동전 던지기(앞/뒤 50:50) = 엔트로피 최대. 결과를 전혀 예측할 수 없다.
> 항상 맑은 사막 날씨 = 엔트로피 최소. 결과가 뻔하다.

---

#### 5-3. 크로스 엔트로피 (Cross-Entropy)

> 두 확률 분포 P(정답)와 Q(예측)가 얼마나 다른지 측정하는 함수. 분류 문제의 손실함수로 사용.

**사용 이유**

분류 모델의 출력(Softmax 확률)과 실제 정답(원-핫 벡터)이 얼마나 다른지를 측정해야 학습 방향을 잡을 수 있다.

**핵심**

- 수식: $$H(P, Q) = - \sum_{i} P(x_i) \log Q(x_i)$$
- **엔트로피와 차이**: 엔트로피 = 하나의 분포 P에 대한 불확실성 / 크로스 엔트로피 = 두 분포 P, Q의 차이
- **왜 분류 손실함수로 쓰나**: $P$ = 실제 정답(원-핫), $Q$ = 모델 예측 확률. 정답을 맞출 확률이 높을수록 손실이 급격히 작아져 효과적인 학습 신호를 줌.
- **음수(-) 부호가 붙는 이유**: log(확률)은 항상 음수(확률 ≤ 1이므로). 손실은 양수여야 하므로 앞에 마이너스를 붙여 양수로 변환.

---

#### 5-4. 미분 → 편미분 → 그래디언트

> 경사 하강법의 수학적 기반

**사용 이유**

"가중치를 어떤 방향으로 얼마나 바꿔야 손실이 줄어드는가"에 답하기 위해 필요하다.

**핵심**

- **미분**: 함수의 순간 변화율. $f'(x)$ = 현재 위치에서 함수가 얼마나 가파른가.
- **편미분**: 다변수 함수에서 하나만 변수 취급하고 나머지는 상수로 고정한 채 미분
  - $\frac{∂f}{∂x}$ 예시: $f(x,y) = x² + y²$이면 $\frac{∂f}{∂x} = 2x$ (y는 상수 취급)
- **그래디언트(∇)**: 모든 변수에 대한 편미분 값들을 모은 **벡터**
  - $∇f = \frac{∂f}{∂x}, \frac{∂f}{∂y}, ...$ 형태
  - 방향과 크기를 가짐 → "가장 가파르게 증가하는 방향"을 가리킴

> [!NOTE]
> **그래디언트가 최대 상승 방향인 이유**
>
> 방향 미분 = $∇f · v = |∇f| × |v| × cosθ$
> - $|v| = 1$ (단위 벡터)이므로: 방향 미분 = $|∇f| × cosθ$
> - 최대가 되려면 $cosθ = 1$, 즉 $θ$ = **0도** ($∇f$와 $v$가 같은 방향일 때)
> - 결론: 그래디언트와 이동 방향이 일치할 때 가장 가파르게 상승
> - **손실 최소화하려면 → 그래디언트의 반대 방향(-)으로 이동 → $θ = θ - η∇L$**

#### 5-5. PyTorch 실습 핵심

> PyTorch로 신경망을 설계하고 학습 파이프라인을 구현하는 방법

**사용 이유**

이론을 알아도 코드로 구현하지 못하면 실무에서 쓸 수 없다. 라이브 코딩 면접에서도 학습 파이프라인을 백지에서 구축할 수 있는 능력이 요구된다.

**핵심 — 모델 설계 구조**

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        # 레이어 정의

    def forward(self, x):
        # 데이터 흐름 정의
        return x
```

> **`nn.Linear` 주의**: `nn.Linear(in, out)`은 선형 가중합(Wx+b)만 수행. **활성화함수는 포함되지 않음.** `forward()`에서 `torch.relu(x)`, `torch.sigmoid(x)` 등을 직접 적용해야 비선형성이 생김. 이걸 빼먹으면 층을 쌓아도 전부 선형 모델.

**핵심 — 학습 루프 5단계**

```python
# 1. 데이터 전처리 & DataLoader
# 2. 모델 설계
# 3. Loss function + Optimizer 설정
# 4. 학습 (순전파 → 손실 → 역전파 → 업데이트)
for epoch in range(num_epochs):
    optimizer.zero_grad()   # gradient 초기화
    output = model(X)       # 순전파
    loss = criterion(output, y)  # 손실 계산
    loss.backward()         # 역전파
    optimizer.step()        # 가중치 업데이트

# 5. 검증 (with torch.no_grad())
```

- `model.eval()` + `torch.no_grad()` 언제, 왜 쓰나:
  - **언제**: 검증(Validation) 또는 테스트 단계
  - **왜**: `model.eval()`은 Dropout 비활성화. `torch.no_grad()`는 gradient 계산을 꺼서 메모리 절약 + 속도 향상.

```
[퍼셉트론] ← 가중합 + 활성화함수
    ↓ 여러 층으로 쌓으면
[ANN / FCNN] ← 비선형성으로 XOR 해결, 복잡한 패턴 학습
    ↓ (이미지에선 공간 정보 손실 + 파라미터 폭증 문제)
[CNN] ← Conv(특징 추출) → Pooling(다운샘플링) → Flatten → FC(분류)
    ↓
[학습 파이프라인]
    순전파 → 손실 계산(MSE / Cross Entropy)
        → 역전파(Chain Rule로 gradient 계산)
        → 경사 하강법(θ = θ - η∇L)
        → (반복, Epoch)
    ↓
[최적화] ← SGD → Adagrad → RMSprop → Adam
    ↓
[수학적 기반] ← 엔트로피 → 크로스 엔트로피 → 편미분 → 그래디언트 증명
```

이번 주는 개별 기술을 배운 게 아니라, **"데이터가 어떻게 모델이 되는가"** 의 전체 흐름을 한 층씩 쌓아 올린 주차였다.
