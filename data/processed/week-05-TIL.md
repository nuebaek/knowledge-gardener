## 📖 학습 내용

### Day 1 (06/08) — Transfer Learning + NLP 입문

#### 1-1. Model Architecture & Pretrained Model

> 모델은 학습 과정을 통해 찾아낸 최적 weight들의 집합. 신경망에서 각 레이어의 구성, 연결 방식, 활성화 함수, 입출력 형태 등 전체 모델의 구조를 뜻한다. Pretrained Model은 이미 거대한 데이터로 학습이 끝나 가중치(파라미터)가 저장되어 있는 모델이다.

**사용 이유**
처음부터 모델을 구축하지 않아도 시간과 자원을 절약하며 활용 가능하고, 이미 일반화 성능이 어느 정도 보장되어 있어 적은 데이터로도 좋은 출발점을 제공한다.

**핵심**
- 딥러닝의 목적: 복잡한 데이터에서 높은 수준의 특징을 자동으로 학습해 weight를 조정하는 것. 순전파로 나온 예측값을 정답과 비교하고, 역전파로 가중치를 조절하는 과정이 매 Epoch마다 자동으로 이루어진다
- 랜덤 초기화 vs 사전학습 모델: 랜덤 초기화는 가중치 0에서 시작해 학습에 오래 걸리고 데이터가 많이 필요하지만, 사전학습 모델은 이미 큰 데이터로 학습된 상태라 적은 학습으로도 좋은 성능
- 에폭을 여러 번 돌릴 때는 이전 에폭에서 업데이트된 파라미터로 다음 에폭을 이어서 시작한다 — 처음부터 다시 하지 않음
- **VGG16**: 16층(Conv 13층 + FC 3층)으로 구성된 CNN 기반 이미지 분류 사전학습 모델. ImageNet으로 사전 훈련된 가중치 제공, 모든 Conv 레이어에서 3×3 필터 사용. 약 1억 3,800만 개(138M) 파라미터로 연산량이 큰 편
- **ResNet**: 입력과 출력의 차이(잔차)를 학습하는 구조. 깊은 신경망의 기울기 소실 문제를 Residual(Skip) Connection으로 해결 — 레이어를 거치지 않고 입력을 바로 다음 레이어로 잇는 지름길 경로를 둬서, 역전파 시 gradient가 그 지름길로 직접 흐를 수 있게 함
- 성능 평가 시 정확도와 손실을 모두 비교해야 함

**비유**
> ResNet의 Residual Connection = 100문제를 풀면서 1번 문제 기억이 희미해지는 걸 막으려고, 1번 풀고 채점한 기억을 2번 풀 때 더해서 진행하는 것

#### 1-2. Transfer Learning

> 사전학습된 모델의 가중치를 그대로 사용하거나 일부만 추가로 조정해서 새 문제에 적용하는 학습 방법. 언어를 배운 사람이 비슷한 언어를 배울 때 기존 지식을 활용하는 것과 유사하다.

**사용 이유**
사전 훈련된 네트워크가 추출한 고수준 특성과 가중치를 새 과제에 그대로 적용해, 시간을 단축하면서도 성능 높은 학습을 효율적으로 할 수 있다.

**핵심**
- **가중치 동결(Freezing)**: `requires_grad = False`로 기존 가중치 업데이트를 차단
- **분류기(Classifier) 교체**: 마지막 레이어를 목적에 맞는 `nn.Linear`로 교체
- **옵티마이저 설정**: 새 레이어 파라미터만 전달해 해당 부분만 학습
- **Fine-Tuning**: 사전학습 모델의 가중치 일부/전체를 새 데이터로 재학습해 미세 조정. Full(모든 파라미터 재학습, 성능↑ 비용↑) / Partial(일부 레이어만, 계산량 절약) / 단계적(레이어를 순차적으로 조정) / 하이브리드(전략 조합) 4가지
- **Feature Extraction**: Conv 레이어(특징 추출부)는 완전히 고정하고 FC 레이어(분류부)만 새로 학습 — Fine-Tuning은 가중치를 같이 업데이트(더 깊이 적응)하는 반면, Feature Extraction은 앞부분을 완전히 잠그고 분류기만 교체(더 빠르고 가벼움)
- **Zero-shot Learning**: 학습에 등장하지 않은 클래스도 예측 가능하게 하는 기법. 사전에 개념·표현을 학습해두면 새 클래스가 등장해도 유사도로 식별 가능 (예: LLM에게 별도 학습 없이 질문하는 것)
- **Few-shot Learning**: 소수의 예시(입력-출력 쌍)를 함께 제공해 문맥을 주고 학습시키는 방법. Zero-shot과 달리 예시가 몇 개 주어진다는 차이

**비유**
> Fine-Tuning = 기존 요리사를 데려와서 새 메뉴에 맞게 다시 훈련시키는 것 / Feature Extraction = 뇌는 기존 것 그대로, 손만 바꾸는 것

---

#### 1-3. Overfitting / Underfitting

> 모델이 학습 데이터에 너무 맞춰지거나(과적합), 아예 학습을 못한(과소적합) 상태

**핵심**

| 상태 | 증상 | 원인 | 해결책 |
|------|------|------|--------|
| Overfitting | Train loss↓, Validation loss↑ | 모델이 너무 복잡함, 데이터 부족, 노이즈 포함 학습 | 교차검증, Regularization, 데이터 증강, Dropout, Early Stopping, 앙상블 |
| Underfitting | Train loss도 높음 | 모델 구조가 너무 단순하거나 학습이 부족 | 모델 복잡도 증가, 데이터셋 확보/증강, 하이퍼파라미터 튜닝 |

**비유**
> Overfitting = 모의고사만 달달 외워서 실전 시험에서 틀리는 것

---

#### 1-4. Dropout

> 학습 중 은닉층의 노드 일부를 매 배치마다 랜덤하게 비활성화해 과적합을 방지하는 정규화 기법

**사용 이유**
모델이 특정 노드에 과도하게 의존하지 못하게 강제해서, 더 고르고 robust한 패턴을 학습하게 만들기 위해.

**핵심**
- 어떤 노드가 꺼져도 다른 경로로 답을 찾도록 만들어, 매번 다른 구조의 서브네트워크를 학습하는 효과 → 앙상블과 유사한 효과를 냄

**비유**
> 팀 프로젝트에서 매번 한 명씩 랜덤하게 빠지게 하면, 나머지 팀원들도 그 역할을 해낼 수 있도록 골고루 실력이 느는 것과 비슷하다

---

#### 1-5. Early Stopping

> Validation loss가 일정 횟수(patience) 이상 개선되지 않으면 학습을 조기 종료하는 기법

**사용 이유**
학습을 계속하면 Train loss는 계속 줄지만 Validation loss는 다시 올라가는(과적합) 시점이 온다. 그 시점을 지나기 전에 멈춰야 일반화 성능이 가장 좋은 모델을 얻는다.

**핵심**
- 중단 기준: 검증 손실이 더 이상 감소하지 않을 때, 검증 정확도가 더 이상 증가하지 않을 때 등 모델 특성에 맞게 설정 가능
- 하이퍼파라미터 튜닝(학습률, 배치사이즈, 에폭 등)의 GridSearch(모든 조합 시도)/RandomSearch(랜덤 샘플링, 더 효율적)와 함께 실무에서 자주 쓰는 과적합 방지 수단

#### 1-6. NLP 기초 — One-Hot Encoding → Word Embedding

> 텍스트 데이터를 컴퓨터가 계산할 수 있는 수치 벡터로 변환하는 과정

**사용 이유**
컴퓨터는 숫자만 계산할 수 있다. 단어를 그대로 넣을 수 없기 때문에 반드시 수치 벡터로 바꾸는 과정이 필요하다.

**핵심**

| 방식 | 특징 | 한계 |
|------|------|------|
| One-Hot Encoding | 단어마다 "해당 위치만 1, 나머지 0"인 벡터 | 차원이 단어 사전 크기만큼 폭발(10만 단어 → 10만 차원), 단어 간 의미 유사성 표현 못함 |
| Word Embedding | 고정된 저차원 밀집 벡터, 의미 유사도 반영 | - |

- **Semantic Space(의미 공간)**: 단어의 의미를 위치로 나타내는 벡터 공간. 유명한 예시로 King - Man + Woman ≈ Queen처럼 의미 연산이 가능
- 대표 기법: **Word2Vec**(주변 단어 예측 방식으로 벡터 학습, Google), **GloVe**(전체 말뭉치의 동시 출현 통계 기반, Stanford)
- **형태소 분석**: 한글은 어근+조사+어미가 붙어 하나의 형태로 나타나므로(예: "먹다/먹었다/먹히다"), 형태소 단위로 쪼개야 모델이 공통 어근("먹")을 공유하는 단어들 간 관계를 파악할 수 있다

#### 1-7. RNN (Recurrent Neural Network)

> 이전 시점의 hidden state를 현재 계산에 사용하며 순차 데이터를 처리하는 순환 신경망

**사용 이유**
텍스트·시계열처럼 순서가 의미를 가지는 데이터를 처리하기 위해. 기존 FCNN/CNN은 각 입력을 독립적으로 처리하지만, RNN은 이전 상태를 기억한다.

**핵심**
- 수식: $h_t = f(W_h h_{t-1} + W_x x_t)$ — $x_t$: 현재 시점 입력 / $h_{t-1}$: 이전 시점 hidden state(과거 기억) / $h_t$: 현재 시점 hidden state / $W_h, W_x$: 모든 시점에서 공유하는 가중치
- "펼쳐서 보면" 같은 RNN 레이어가 시간 축으로 반복 적용되는 구조 — t=1 → t=2 → t=3 순으로 동일한 가중치를 공유하며 계산
- **Cell vs Layer**: Layer는 시퀀스 전체를 처리하려고 같은 구조가 시간 축으로 반복되는 한 층, Cell은 그 레이어가 각 시간 단계에서 한 번씩 수행하는 최소 계산 단위
- **한계 2가지**: (1) 병렬 처리 불가 — $h_t$를 구하려면 $h_{t-1}$이 먼저 필요해 순차 연산만 가능 (2) 장기 의존성 문제 — 역전파 시 기울기를 시간 역방향으로 계속 곱하다 보니 0으로 수렴해 초기 정보가 소실됨
- **BPTT(Backpropagation Through Time)**: RNN에서 시간 축을 펼쳐 역전파하는 방식. 일반 역전파(출력층→은닉층→입력층)에 더해 시간 방향(t=5→t=4→t=3...)으로도 역전파하며 시간 전체에 걸쳐 공유되는 가중치를 업데이트

**비유**
> 전화 게임(telephone game): 10명을 거치면 처음 말이 뭐였는지 아무도 기억 못 하는 것처럼, RNN도 시퀀스가 길어지면 초기 정보가 점점 흐려진다

#### 1-8. LSTM (Long Short-Term Memory)

> RNN의 장기 의존성(Long-term Dependency) 문제를 해결하기 위해 Cell State와 3개의 게이트를 추가한 순환 신경망

**사용 이유**
RNN은 hidden state 하나로 모든 정보를 전달하다 보니 기울기 소실이 발생해 오래된 정보를 유지하지 못한다. 예를 들어 "The news that Startupcode is a company **is** true"에서 마지막 is를 올바로 이해하려면 맨 앞 "The news"를 기억해야 하는데, RNN은 이런 장거리 의존성을 놓치기 쉽다.

**핵심**
- RNN vs LSTM: RNN은 hidden state 하나로 모든 정보를 전달 → 기울기 소실 / LSTM은 Cell State(장기 메모리) + Hidden State(단기 출력) + 3개 Gate로 선택적 기억
- **게이트 구조**: Forget Gate(이전 Cell State에서 뭘 잊을지, 0=완전히 잊음~1=완전히 유지) / Input Gate(새 정보를 얼마나 추가할지) / Output Gate(Cell State의 어떤 부분을 Hidden State로 내보낼지)
- **Cell State**: LSTM 내부의 장기 기억 고속도로. 덧셈 연산으로 갱신되기 때문에 gradient가 안정적으로 흐른다
- LSTM의 핵심은 모든 정보를 무조건 기억하는 게 아니라, 중요한 정보는 오래 유지하고 덜 중요한 정보는 선택적으로 잊는 구조라는 점

### Day 2 (06/09) — NLP 심화 + Transformer 등장

#### 2-1. 메타인지 기반 회고

> 사실 나열(1D)을 넘어, 내가 한 것을 관찰하고 평가(2D)하는 글쓰기 방식

**사용 이유**
포트폴리오·면접에서 사실 나열만 하면 평범해 보인다. "내가 뭘 배웠고 어떻게 성장했는지"에 대한 관찰이 설득력을 만든다.

**핵심**
- **1D**: "FastAPI로 API 서버 만들었다" → 사실
- **2D**: "FastAPI를 쓰면서 HTTP 추상화의 의미를 처음 느꼈다" → 메타인지
- **AI 활용 사이클**: 내가 초안 → AI 피드백 요청 → 이해 → 내 손으로 재수정. 처음부터 AI에게 맡기면 안목이 안 생긴다

---

#### 2-2. SLM vs NNLM

> 통계 기반(빈도표)에서 신경망 기반(확률분포 벡터)으로의 전환

**사용 이유**
언어 모델(LM)은 앞의 단어들이 주어졌을 때 다음 단어가 나타날 확률 분포 $P(w_t | w_1, ..., w_{t-1})$을 학습한다. 이 확률을 어떻게 계산하느냐에 따라 SLM과 NNLM으로 나뉜다.

**핵심**

| 방식 | 핵심 | 한계 |
|------|------|------|
| SLM (N-gram) | 빈도표로 확률 계산: $P(w_t\|w_{t-2},w_{t-1}) = \frac{Count(w_{t-2},w_{t-1},w_t)}{Count(w_{t-2},w_{t-1})}$ | 학습 데이터에 없던 조합은 확률 0 (블랙스완 예측 불가) |
| NNLM | 단어를 Word Embedding으로 밀집 벡터화 후 신경망으로 예측 | 벡터 공간의 유사성으로 본 적 없는 패턴도 추론 가능 |

- **N-gram**: n-1개의 단어를 조건으로 다음 단어를 예측하는 통계 기반 모델. Bigram(앞 1개 단어) / Trigram(앞 2개 단어) — n이 클수록 넓은 문맥을 반영하지만 필요한 학습 데이터도 급증
- SLM은 세상을 관측된 것만으로 보기 때문에 블랙스완(한 번도 없던 조합)을 영원히 예측하지 못하지만, NNLM은 벡터 공간의 유사성으로 추론 가능
- 발전 계보: sLM → NPLM(NNLM) → RNN/LSTM 언어모델 → Transformer(현재 LLM)
- **LLM은 근본적으로 "다음 단어를 예측하는 모델"** — 고도화된 자동완성이라고도 볼 수 있다. N-gram과 다른 점은 단어 빈도표가 아니라 대규모 데이터로 학습된 가중치를 사용한다는 것

---

#### 2-3. Seq2Seq (Sequence to Sequence)

> 인코더가 입력 시퀀스를 Context Vector로 압축하고, 디코더가 다른 길이의 출력을 생성하는 구조 (2014, Google)

**사용 이유**
기본 RNN은 입력 길이 = 출력 길이여야 한다. 번역·챗봇처럼 입출력 길이가 다른 태스크를 처리하기 위해 등장.

**핵심**
```
입력 문장 → [인코더] → Context Vector → [디코더] → 출력 문장
```
- 인코더: 입력 문장을 순차적으로 RNN 계열 모델에 통과시켜 문장 전체의 의미가 농축된 하나의 벡터(Context Vector)로 압축
- 디코더: Context Vector를 넘겨받아 한 토큰씩 순차적으로 출력을 생성
- 학습 시에는 **교사 강요(Teacher Forcing)**로, 인코더가 전달한 정보와 실제 정답을 함께 입력해 디코더가 다음 출력을 예측하도록 학습. 테스트 시에는 이전 예측 결과를 다음 입력으로 사용
- 입력 시퀀스의 순서를 뒤집는 방식으로 성능을 개선할 수도 있음 — Context Vector에 앞쪽 단어 정보가 더 잘 보존됨
- **한계**: 고정된 크기의 Context Vector 하나에 모든 정보를 압축하기 때문에 문장이 길어질수록 정보 손실이 발생 → 이 문제를 해결하기 위해 Attention Mechanism이 등장

**비유**
> 인코더 = 긴 책을 뒷표지 한 줄로 요약하는 편집자 / 디코더 = 그 한 줄을 다른 언어로 풀어쓰는 번역가

---

#### 2-4. Transformer 등장 배경

> RNN/Seq2Seq의 순차 연산 한계를 극복하기 위해 등장한 병렬 처리 기반 아키텍처 (2017, "Attention Is All You Need")

**사용 이유**
RNN/Seq2Seq의 순차 연산 병목을 완전히 제거하고, 긴 문맥도 직접 참조할 수 있도록 하기 위해.

**핵심 구성 요소**

| 요소 | 역할 |
|------|------|
| Positional Encoding | 단어 벡터에 위치 정보를 더해 순서 없이 넣어도 순서를 알 수 있게 함 |
| Self-Attention | 모든 토큰이 서로를 동시에 참조 → 병렬 처리 가능 |
| Residual Connection | 레이어 출력 + 입력을 더해 기울기 지름길 확보 |
| Feed Forward | 각 위치에서 독립적으로 적용되는 FC 레이어 |
| Softmax 출력 | 어휘 전체에 대한 확률 분포 반환 |

```
RNN:         x1 → x2 → x3 → x4  (순차)
Transformer: x1, x2, x3, x4 → 동시에 전부 참조  (병렬)
```

**비유**
> RNN = 책을 처음부터 끝까지 순서대로 읽어야 이해하는 사람 / Transformer = 전체 페이지를 펼쳐놓고 필요한 부분을 동시에 보는 사람

---

### Day 3 (06/10) — Transformer 아키텍처

#### 3-1. Input Pipeline

> 자연어 → 토크나이징 → 토큰 임베딩 → 패딩 → 포지셔널 인코딩 순으로 변환하는 5단계 전처리 파이프라인

**핵심**
- **토크나이징(Tokenizing)**: 문장을 분절 규칙과 사전을 참조해 의미를 가지는 토큰으로 쪼개고 정수 ID로 변환. 최신 모델은 공백 기준이 아니라 통계적 기준으로 단어를 더 작은 서브워드(Sub-word)로 분리해, 사전에 없는 합성어에도 대처
- **토큰 임베딩(Token Embedding)**: 10만 차원이 넘는 방대한 어휘 사전의 토큰을 256차원, 512차원 등 고정 길이 저차원 밀집 벡터로 매핑. 벡터 안의 숫자는 고정된 게 아니라 모델이 학습하면서 계속 최적화하는 학습 파라미터
- **패딩(Padding)**: 배치 내 시퀀스 길이를 동일하게 맞추기 위해 빈 자리를 0으로 채움
- **Positional Encoding**: Transformer는 순환 구조(재귀 연산)가 없어 모든 단어가 동시에 병렬로 입력되므로, 그대로 두면 단어 순서를 구별할 수 없다. 이를 극복하기 위해 단어의 위치 정보를 사인/코사인 함수 등으로 인코딩한 벡터를 토큰 임베딩 벡터에 더해준다

---

#### 3-2. Encoder / Decoder 구조

> 인코더는 입력 전체의 관계를 파악해 맥락 벡터(Context Vector) 시퀀스를 만들고, 디코더는 이를 바탕으로 출력을 생성

**핵심**

| 구성 | 역할 | 대표 모델 |
|------|------|-----------|
| Encoder-only | 문장의 감정 분석·분류처럼 다음 단어 생성이 필요 없는 태스크 | BERT |
| Decoder-only | 다음 토큰을 순차적으로 예측·생성하는 텍스트 생성 | GPT, 현대 LLM 대부분 |
| Encoder-Decoder | 번역, 요약처럼 두 시퀀스를 다 다루는 태스크 | T5 |

- **인코더**: 입력 문장의 각 토큰을 분석해, 문장 전체 의미가 깊게 반영된 맥락 벡터(Context Vector) 시퀀스로 변환
- **디코더**: 인코더가 추출한 맥락 벡터와 이전까지 생성된 토큰들을 참조해 다음 토큰을 순차적으로 예측·생성. 현대 LLM들은 효율성을 위해 인코더 없이 Decoder-only 구조로 구성되는 것이 대세

---

#### 3-3. Attention (Q, K, V)

> Query와 Key의 유사도를 계산해 Value에 가중치를 부여하는 핵심 메커니즘 — 현재 토큰이 문장 내 다른 토큰들 중 어느 정보에 더 큰 비중을 두고 참고할지 수치화하는 연산

**사용 이유**
Seq2Seq는 Context Vector 하나에 모든 정보를 압축해 긴 문장에서 정보 손실이 발생했다. Attention은 모든 토큰 쌍의 관련성을 직접 계산해 이 문제를 해결한다.

**핵심**
- **Query**: 현재 내가 찾고 싶은 것(질의) / **Key**: 각 토큰의 "나는 이런 정보다" 태그(고유 기준) / **Value**: 실제로 가져올 내용
- **Q, K, V 행렬**: 입력 벡터 $X$에 각기 다른 가중치 행렬($W_Q, W_K, W_V$)을 곱해 생성. Transformer 학습의 핵심은 이 $W_Q, W_K, W_V$를 정교하게 업데이트하는 것
- **계산 원리**: $Q$와 $K$의 전치행렬($K^T$)을 곱(내적)해 단어 간 유사도 스코어를 얻고, 값이 너무 커지지 않도록 $\sqrt{d_k}$로 스케일링한 뒤 Softmax로 합이 1이 되는 가중치 벡터로 변환. 이 가중치를 실제 정보인 $V$ 행렬에 곱해 최종 어텐션 맥락 벡터를 얻는다 — `Attention(Q,K,V) = softmax(QK^T/√d_k)V`
- **DB 검색 비유의 기원**: 사용자의 검색어(Query)를 DB 목차(Key)와 대조해 실제 결과값(Value)을 가져오는 전통적 DB 검색 원리에서 착안. 이를 응용해 과거 계산된 K, V를 메모리에 저장해두고 재활용하는 **KV 캐시** 최적화 기법이 파생됨
- **Multi-Head Attention**: 어텐션 연산을 한 개가 아니라 여러 개의 독립적인 헤드로 다발적으로 수행. 단어 간 관계를 문법적·의미적 등 다양한 관점에서 동시에 파악하고, 각 헤드의 결과를 병합(Concatenate)한 뒤 최종 가중치 행렬($W_O$)을 곱해 원래 차원으로 복구

---

### Day 4 (06/11) — Transformer 세부 메커니즘

#### 4-1. Masking

> Attention이 보면 안 되는 위치를 가리는 기법

**사용 이유**
디코더는 병렬 연산 특성상 뒤에 위치한 미래 단어를 모델이 미리 훔쳐보는 정보 유출(Information Leakage) 문제가 발생할 수 있다. 학습 중 미래 토큰을 미리 보면, 다음 단어를 예측하는 능력 자체를 학습할 기회를 잃는다.

**핵심**

| 종류 | 목적 |
|------|------|
| Padding Mask | 패딩 토큰(의미 없는 0)을 Attention 계산에서 제외 |
| Causal (Look-ahead) Mask | 디코더에서 현재 위치 이후(미래) 토큰을 가림 |

- 어텐션 스코어 행렬에서 자기 자신 및 과거 토큰 위치만 통과시키고, 미래 토큰 위치는 마이너스 무한대($-\infty$)로 가려 Softmax를 통과할 때 가중치가 0이 되도록 원천 차단

---

#### 4-2. Residual Connection (Skip Connection)

> 레이어의 입력을 출력에 더해서 기울기 소실 문제를 완화하는 기법

**사용 이유**
신경망이 깊어지면 역전파 시 기울기가 점점 작아져 앞쪽 레이어 가중치가 거의 학습되지 않는 기울기 소실(Vanishing Gradient) 문제가 생긴다. 입력을 바이패스로 더해주면 기울기가 직접 흐를 수 있는 경로가 생긴다.

**핵심**
- 수식: `Output = X + Sublayer(X)` (Transformer에서는 `LayerNorm(MHA(x) + x)`)
- 서브 레이어를 통과한 결과값에 아무 연산을 하지 않은 원래 입력값 $X$(항등함수)를 그대로 더해주는 구조
- 미분을 진행할 때 항등함수의 미분값인 1이 기본적으로 더해지므로, 신경망이 깊어져도 오차의 기울기가 0으로 수렴해 학습이 멈추는 현상을 방지
- **항등함수(identity)**: 레이어가 아무것도 배우지 못해도 입력이 그대로 흘러가므로 최소한의 성능은 보장됨

---

#### 4-3. Layer Normalization vs Batch Normalization

> 각 레이어의 출력 분포를 안정화해 학습을 안정적으로 만드는 기법

**핵심**

| 방식 | 정규화 기준 | 주로 사용 |
|------|------------|-----------|
| Batch Normalization | 배치 내 같은 피처끼리 | CNN, 이미지 |
| Layer Normalization | 하나의 샘플 내 모든 피처 | Transformer, NLP |

- 어텐션과 잔차 연결을 거친 출력 벡터 성분들이 들쭉날쭉 폭주하는 것을 막기 위해, 각 벡터 성분의 평균과 표준편차를 구해 표준화
- 단순 표준화에 그치지 않고, 모델이 층별 상황에 맞는 최적 분포를 스스로 찾아가도록 학습 가능한 파라미터인 스케일($\gamma$)과 절편($\beta$)을 추가로 곱하고 더해 모델을 안정화

## 🔗 이번 주 개념 흐름

```
[사전학습 모델]
    VGG16, ResNet — 이미 학습된 특징 추출기
    ↓ Transfer Learning
    Freeze 기존 가중치 + 마지막 레이어만 교체
    ↓ 성능 개선
    Dropout / Early Stopping / Regularization

[NLP: 텍스트를 벡터로]
    One-Hot Encoding → Word Embedding
    ↓ 언어 모델
    SLM (N-gram) → NNLM (신경망 기반)

[순서 정보 처리]
    RNN — Hidden State로 순차 전달 (병렬 불가)
    ↓ 장기 의존성 문제
    LSTM — 게이트 구조로 장기 기억 유지
    ↓ 입출력 길이 불일치
    Seq2Seq — 인코더(압축) + 디코더(생성)

[Transformer — 병렬 처리의 등장]
    Input Pipeline: 토크나이징 → 임베딩 → Positional Encoding
    ↓ 핵심 메커니즘
    Self-Attention: Attention(Q, K, V) — 모든 토큰 관계 한 번에 파악
    ↓ 세부 기법
    Masking (Padding / Causal) — 보면 안 되는 토큰 차단
    Residual Connection — 기울기 소실 완화
    Layer Normalization — 분포 안정화
    ↓
    [현대 LLM의 근간: GPT, BERT, Claude ...]
```

이번 주는 "이미지 모델의 재활용"에서 시작해, **텍스트 처리의 진화(RNN → Seq2Seq → Transformer)** 를 단계적으로 쌓아 올리며 현대 LLM의 아키텍처 기반을 이해한 주차였다.
